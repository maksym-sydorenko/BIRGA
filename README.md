# BIRGA

BIRGA is a C# project designed for **preparing and processing stock market data for AI/ML models**.  
It provides tools for collecting, cleaning, and structuring financial datasets, making them suitable for training predictive algorithms and research in quantitative finance.

---

## 🔧 Technologies
- **Language:** C#
- **Platform:** .NET
- **Architecture:** Modular, extensible
- **Focus:** Data preprocessing for AI/ML pipelines

---

## 📊 Key Features
- Import and parse raw stock market data (CSV, API sources)
- Normalize and clean datasets for consistency
- Generate training-ready datasets for machine learning models
- Simulate trading operations for synthetic data generation
- Logging and basic analytics for dataset validation

---

## 🚀 Getting Started

### Requirements
- .NET SDK (version 6.0 or newer)
- Visual Studio / Rider / VS Code

### Clone the repository
```bash
git clone https://github.com/maksym-sydorenko/BIRGA.git
cd BIRGA
```

### Build and Run
```bash
dotnet build
dotnet run
```
